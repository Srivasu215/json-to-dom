The Story: The Foundry & The Canvas

Decoupled Two-Tab workflow adhering to strict modular discipline: separate CSS and JS across Header, Left Workspace, and Right Monaco Editor, with 100% instruction-driven event bindings.

Tab 1: The Foundry (Supplier)

Editable Monaco studio with element selector dropdown and "Show all" button. Clicking [▶ Render in Tab 2] beams the active JSON spec across BroadcastChannel and localStorage.

Tab 2: The Canvas (Consumer)

Pure HTML canvas with zero buttons, zero headers, and zero Monaco bloat. Listens silently and compiles live HTML into <body id="app"> using json-to-dom.
